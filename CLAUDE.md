## Hướng Dẫn & Lệnh Thường Dùng

- **Môi trường phát triển cục bộ:** `npm run dev` (chạy tại cổng 8080)
- **Kiểm tra build:** `npm run build`
- **Deploy nhanh lên Cloudflare Pages:** `npm run deploy` (hoặc push commit lên nhánh `main`)
- **Tài liệu hướng dẫn deploy chi tiết:** [docs/DEPLOY.md](docs/DEPLOY.md)
- **Trang web chính thức (Production):** [https://vieccanlam.pages.dev](https://vieccanlam.pages.dev)
